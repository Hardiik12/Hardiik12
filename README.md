### 🚀 What I'm Working On

**CollabSphere** — A college-student collaboration platform for skill/interest/goal-based teammate matching, built as a purpose-built alternative to Discord/WhatsApp for academic project teams.
- Full-stack app (React/TypeScript, Node, PostgreSQL) with real-time features
- Custom "Volt & Ink" visual identity and GSAP-driven landing page animations
- Currently hardening security (rate limiting, RBAC, input sanitization) and wiring up transactional email

### 🧠 Recent Projects

- **AlgoTrade** — Java-based educational stock trading platform (27 classes across model, persistence, engine, UI, and algorithm layers), paired with an interactive HTML class-diagram explorer and a DSA algorithm showcase.
- **Autonomous Cleaning Robot Simulation** — AI capstone project implementing BFS, DFS, UCS, and A* pathfinding on an 8×8 grid, built with Python/Flask + HTML/CSS/JS.
- **E-Commerce Behavior Analysis** — Data science coursework project analyzing e-commerce trends, delivered as a 15-slide report generated programmatically with `python-pptx`.
